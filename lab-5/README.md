# №5 — парсинг, pandas та Flask

[Повний звіт із кодом, результатами та скріншотами](REPORT.md).

У цьому каталозі після встановлення кореневих залежностей:

```bash
python -m src.web_scraper https://example.com
python -m src.data_analysis
python -m pytest -q
python -m src.app
```

Остання команда запускає [локальний сервер](http://127.0.0.1:5000).
Форми обчислюють середню ціну категорії та отримують заголовки h1/h2/h3 із URL.
Сторінка працює без AI API. Вона показує лише наявність OPENAI_API_KEY,
а не його значення; повний API-клієнт знаходиться в роботі №4.

Віддалена сторінка може не мати заголовків: example.com на момент перевірки
повернув HTML без h1–h3. Це коректний порожній результат.
Відтворюваний приклад із трьома заголовками — `data/sample_page.html`;
кореневі скрипти перевірок і скріншотів автоматично піднімають для нього
тимчасовий HTTP-сервер. Аналіз CSV: категорія A, 3 рядки, середнє 526.67.
