# Скріншоти для звіту лабораторної №5

Зробіть власні скріншоти після запуску на вашому комп'ютері:

1. `python -m src.web_scraper https://example.com` з отриманими заголовками;
2. `python -m src.data_analysis` із кількістю рядків і середньою ціною;
3. `pytest -q` з усіма успішними тестами;
4. сторінка Flask `http://127.0.0.1:5000` у браузері та результат аналізу;
5. за бажанням — блок стану Gemini після локального налаштування ключа.

Не показуйте `.env`, API-ключ або інші секретні дані.
