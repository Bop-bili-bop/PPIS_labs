# Зображення фактичного виконання

PNG створено `scripts/capture_evidence.py` із журналів `results/*.txt`.
Вони показують журнали у браузері. Для №4–5 файли `flask-*.png` — скріншоти
живого HTTP-застосунку. Запустіть `scripts/verify_all.py` перед повторним
зняттям зображень. Живий AI-діалог без ключа не виконувався.
