# Лабораторна робота №4–5 — Python за допомогою ChatGPT

Це **одна лабораторна робота** за спільною методичкою №4–5:
OpenAI API, чат-бот, алгоритм LCS, парсинг HTML, аналіз CSV та Flask.
Усі модулі мають спільні налаштування, залежності й набір тестів.

[Єдиний звіт з кодом і результатами](REPORT.md).

## Встановлення й запуск

З кореня репозиторію:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r lab-4-5/requirements.txt
cd lab-4-5
python -m pytest -q
python -m src.lcs ABCBDAB BDCABA
python -m src.data_analysis
python -m src.web_scraper https://example.com
python -m src.app
```

Flask доступний на [127.0.0.1:5000](http://127.0.0.1:5000).
Форми обчислюють середню ціну категорії та отримують заголовки h1/h2/h3.
CSV категорії A: 3 рядки, середня ціна 526.67. LCS демонстраційних рядків має
довжину 4. Для цих частин API-ключ не потрібний.

## OpenAI API і чат-бот

У цьому ж каталозі:

```bash
cp .env.example .env
```

У `.env` задайте `OPENAI_API_KEY` своїм ключем та `OPENAI_MODEL` моделлю,
доступною акаунту. Єдиний `.env` використовується клієнтом і Flask.

```bash
python -m src.chatbot
python -m src.generate_algorithm
```

Чат зберігає історію та завершується через exit/quit. Генератор надсилає
підготовлений LCS-запит і друкує відповідь без автоматичного виконання коду.
Живі запити потребують налаштованого акаунта; ключ не додається до Git.
Без налаштувань програма завершується з поясненням і кодом 1.

У виконанні роботи живий API-запит не здійснювався: ключ не надавався.
Логіка клієнта перевірена з підміною API у спільному наборі з **30 тестів**.
[Офіційна документація Responses API](https://developers.openai.com/api/docs/guides/text?lang=python).

## Приклади й докази виконання

Один каталог `results/` містить журнали всіх частин; `screenshots/` — їх
зображення й скріншоти живого Flask-сервера. `data/sample_page.html` —
відтворюваний приклад із трьома заголовками, який кореневі скрипти автоматично
публікують через тимчасовий локальний HTTP-сервер.

Публічна сторінка може не містити h1–h3: це коректний порожній результат.
Початковий Gemini-клієнт збережено як необов'язковий приклад; для нього є
`requirements-gemini.txt` та змінні GEMINI_API_KEY/GEMINI_MODEL.
