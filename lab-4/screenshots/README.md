# Скріншоти для звіту лабораторної №4

Зробіть власні скріншоти після запуску на вашому комп'ютері:

1. створення/активація середовища та успішне `pip install -r requirements.txt`;
2. команда `python -m src.lcs ABCBDAB BDCABA` з LCS і довжиною 4;
3. команда `pytest -q` з усіма успішними тестами;
4. розмова у `python -m src.chatbot` **після** додавання власного API-ключа.

Не показуйте `.env`, API-ключ або інші секретні дані на скріншотах.
