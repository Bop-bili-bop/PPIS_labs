# Лабораторные работы 1–3: вариант 6 «Грип»

Репозиторий содержит три учебные реализации одной и той же модели знаний о
гриппе. Это демонстрационные экспертные системы, **не** средство медицинской
диагностики.

## Состав проекта

| Работа | Язык | Представление знаний |
|---|---|---|
| [Лабораторная 1](lab1/README.md) | Prolog | факты наблюдений, промежуточные признаки и диагностические правила |
| [Лабораторная 2](lab2/README.md) | Common Lisp | рекурсивный обход бинарного дерева решений |
| [Лабораторная 3](lab3/README.md) | CLIPS | продукционные правила и вывод новых фактов |
| [Лабораторна 4](lab-4/README.md) | Python + Gemini | API, чат-бот і алгоритм LCS |
| [Лабораторна 5](lab-5/README.md) | Python | BeautifulSoup, pandas, Flask і стан Gemini |

## Согласованность модели

Во всех трех работах исходными признаками служат острое начало, повышение
температуры, озноб, головная боль, слабость, мышечная/телесная ломота и
светобоязнь. Основной вывод требует сочетания острого начала, лихорадки и
системных проявлений; умеренное повышение температуры с более слабым набором
признаков может дать учебный вывод о легком гриппоподобном проявлении; если
ключевых данных не хватает, результатом является недостаточность свидетельств.

Формы реализации различаются, но смысл остается единым:

1. **Prolog** хранит симптомы пациентов как отношения и получает вывод через
   унификацию, правила и поиск с возвратом.
2. **Common Lisp** задает последовательность тех же проверок явным бинарным
   деревом и рекурсивно выбирает ветви «да»/«нет».
3. **CLIPS** представляет наблюдения фактами и поэтапно активирует правила,
   которые формируют свидетельства, оценку выраженности и итоговый результат.

В каждом каталоге приведены три сопоставимых сценария: выраженное сочетание
признаков, легкое проявление и случай с недостаточными данными. Подробные
команды запуска и ожидаемые результаты находятся в README соответствующей
работы.
